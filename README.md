# Hi, I'm Leonardo 👋

Computer Engineering student at the **University of Padua** (Italy), interested in
**numerical simulation and scientific computing**, and heading towards a Master's in
Computational Science and Engineering.

I like projects where code meets real data: building a model, validating it honestly
against reality, and making it run fast. Formula 1 is my favourite testbed.

### Projects

- **[F1 Qualifying Simulator](https://github.com/Leonardo-Marin/F1-Qualifying-Simulator)**
  Monte Carlo simulator of F1 qualifying in C++20 with a Python/FastF1 data pipeline.
  It predicts the grid from free practice data and is validated out-of-sample on the
  2026 season (calibration vs. test races, baseline comparison, calibrated probabilities).
  Parallel execution on a custom thread pool.

- **[Stack Adapter](https://github.com/Leonardo-Marin/Stack-Adapter)**
  The J2SE 1.4.2 `Stack`/`List` API rebuilt on top of Java ME CLDC 1.1 (Adapter pattern),
  developed with TDD: 237 documented JUnit tests.
